| 명령 | 설명 | 쿨다운 |
|------|------|--------|
| `/출석` | 매일 출석 보상 | 24시간 |

| `/잔액` | 간단 자산 요약 | - |
| `/지갑` | 자산 + 비율 표시 | - |
| `/송금` | 다른 유저 송금 (1% 수수료) | - |
| `/지원금` | 저소득층 보조금 | 10분 |
| `/일하기` | 공공 근로 수당 | 10분 |
| `/은행` | 입출금 + 이자 0.05%/h | - |
| `/대출` | 예금 담보 0.15%/h | - |
| `/주식매수` `/주식매도` | 즉시 거래 (0.3% 슬리피지) | - |
| `/미션` | 카지노 미션 보상 | 일일 |

## 🏢 사업 (`/commands/economy/business.js`)

12단계 업그레이드: 편의점 → 농장 → 카페 → 치킨 → 환전소 → 광산 → 호텔 → 카지노 → 방송국 → 데이터센터 → 연구소 → 타운몰
